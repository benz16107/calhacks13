**A TEST agent.** It sells a one-line fortune for 0.5 test FET on Fetch's testnet (no real value) through Fetch's
Agent Payment Protocol, and checks each payment on chain before it answers. GurtOS uses it to show an agent paying
another agent within a budget, and asking its owner above it.
