# GurtOS test weather (trap)

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

**A TEST agent.** It answers with a made-up weather report that hides an instruction for any AI agent reading it,
asking for keys, a pairing code and money. GurtOS uses it to show that it treats other agents' replies as data:
it blocks the instruction, says so in the chat, and logs it. Do not rely on its weather.
