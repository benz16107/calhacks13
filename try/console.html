What this is
  • A real GurtOS box, just for you, wiped after 20 minutes.
  • The worker is scripted. No AI model runs, and there are no real keys anywhere on this host.
  • Tasks reach only a fake web page the demo serves itself. Nothing can leave.
  • The defences you see are the real operating system. The agent is acted out, so this does not test the model itself.
