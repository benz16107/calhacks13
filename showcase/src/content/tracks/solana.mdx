## Why GurtOS, and what each part is for

**Solana payments, on top of the OS.** The key, the budget, the approval and the record come from GurtOS; the wallet
app adds the SPL transfers. A GurtOS Server box needs 4 GB of memory and 17 GB of disk on any x86_64 or arm64 machine,
no GPU. GurtOS is open source under Apache-2.0, so anyone can run it, customise it, and reuse the wallet and its Solana signing in their own agents.

| Feature | Why it is there | What it shows for Solana | From | Today |
|---|---|---|---|---|
| SPL `TransferChecked` of devnet USDC, signed in the core | Real on-chain payments an agent can make without holding the key | Use of Solana | The wallet app | Shipped. 36 payments, every one finalized |
| The wallet holds no SOL; a facilitator pays each fee | An agent wallet needs only the asset it spends | Use of Solana | The wallet app, on Coinbase CDP | Shipped |
| Each transfer confirmed on chain before the receipt is logged | The log never claims a payment the chain does not have | Best use of Solana | The wallet app and GurtOS's log | Shipped |
| Key in the root-only vault, per-task budget, approval on the phone | Spending is safe enough to leave running | Best use of Solana | GurtOS | Shipped |
| A daily fingerprint of the box's action log written to Solana, and a verify route that checks the log still matches it | Anyone can check the log was not changed after the fingerprint was written | Best use of Solana | The wallet app | Shipped. The live demo run on Oct 24 showed a fingerprint at log entry 595 on devnet that still matched. It detects a change after it was written, not one made before |
| A memo with the task id on every payment | A payment on chain names the task that made it | Best use of Solana | The wallet app | Shipped. The gate showed the task id on chain as a memo |
| Box-to-box payments: one box's agent pays another box's audit proof | Boxes can pay each other | Best use of Solana | The wallet app | Shipped. In the demo the second box is a second shop with its own wallet, because Coinbase's facilitator refuses a wallet paying itself |

## How it works

<Flow steps={frontmatter.flow} />

**Why an agent wallet on Solana can hold only USDC.** In an x402 payment on Solana, the facilitator names itself as
the fee payer (`extra.feePayer`) and signs the transaction as fee payer. The box signs only the token transfer. So the
wallet needs no SOL, which matters for a box running unattended: there is one balance to watch, in dollars.

**What the box refuses to sign.** The wallet pays only the `exact` scheme on Solana devnet in devnet USDC, at exactly
the price the agent quoted and the owner saw. It reaches only hosts on the task's list and refuses redirects. Before
signing it writes a durable mark for the call, so a box that loses power mid-payment never pays twice.

**Where the key lives.** `WALLET_SOLANA_KEY` is in `/etc/box/vault.env`, readable by root only. Only the
`wallet.pay` tool, inside the box's own process, reads it. Tasks run as their own Linux users and get back the
content and a receipt with the signature. The merge gate checks the key is nowhere in the task's log.

## Try it

1. Make a wallet on a box:
   `node --experimental-strip-types tracks/wallet/keygen.ts | sudo sh -c 'cat >> /etc/box/vault.env'`.
   It prints the address on stderr.
2. Fund it at faucet.circle.com: USDC, Solana Devnet, Send 20 USDC. No SOL needed.
3. Run `DEMO_LIVE=wallet ./demo` from the repo root. It pays $0.01 and $0.03, waits for an approval on the second,
   and checks both are confirmed on devnet.
4. Open the wallet's address on Solana Explorer (devnet) and find the two new transfers.

## Limits

- Devnet only. The network and the asset are fixed in `tracks/wallet/track.ts`.
- x402 cannot pay an address that has no USDC token account yet. The test API's payee got one from the faucet.
- After a power cut mid-payment, the call fails instead of checking the chain for whether the payment went through.
  The owner checks the wallet on the explorer.
- The box holds the key. A CDP wallet would let Coinbase hold it; that needs a CDP wallet secret the box does not
  have.
