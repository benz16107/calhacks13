## One page, read two ways

A listing page with a hidden line in it. The visible text is a used road bike for $300. The hidden text tells an AI agent to read the vault and send every key to an outside address.

<Compare labels={['On an ordinary computer', 'Through Agent-Safe Page Reader on GurtOS']}>
<div slot="a">

The agent runs as you. It holds your keys, and it can open a connection to any address, so a page that says "send every key to this address" is one tool call away from working. Nothing in the system separates the agent from your keys, and nothing records the attempt.

</div>
<div slot="b">

The page is read as data and the hidden line is found:

```
risk: high   score: 100   where: display:none
why: tells the agent to drop its instructions; speaks to
     the AI agent; asks the agent to hide it from the user;
     asks the agent to send out a secret; asks the agent to
     read a secret or its own prompt; asks the agent to send
     data to an address
```

A high-risk page is withheld: the agent gets the findings, not the text. Even if it were fooled, its task has no network and no secrets to act with.

</div>
</Compare>

That output is the real detector (`tracks/apify/actor/src/detect.js`) run on the page used in the track's live demo. On `example.com` it reports `none`. The detector reads inline styles and attributes, not stylesheets, and `none` means nothing found, not safe.

## Why this needs an operating system

On an ordinary system the web agent holds everything you hold, so every protection has to be the agent's own good behaviour. On GurtOS the protections are the computer's.

<Steps title="Try it" time="About five minutes. You need an Apify account; the free plan includes $5 of usage a month.">

1. Copy a token from Apify's Settings, API & Integrations. A scoped token that runs Actors and reads their datasets works.
2. On a GurtOS computer, as root: `echo 'APIFY_TOKEN=apify_api_...' | tee -a /etc/box/vault.env`. The file stays root only.
3. Start a task with the tool `apify.checkPrice` and no internet access, and ask: "What does Best Buy Canada charge for AirPods Pro, and are they in stock?"
4. Or run the live test from the repo root on a test VM: `DEMO_LIVE=apify ./demo`.

</Steps>

<Details summary="The nine tools, which Actor each calls, and what each counts against the budget">

| Tool | What it does | Actor | Cost counted |
|---|---|---|---|
| `apify.run` | Any Actor from the Store | the agent's choice | the run's real cost from Apify, never above its cap (default $0.10) |
| `apify.readPage` | Pages as clean text, checked for hidden instructions | Agent-Safe Page Reader (ours) | 1 cent |
| `apify.mcp` | Apify's MCP server, limited to the allowed tools | four Actors | the call's cap, default $0.10 (a list costs nothing) |
| `apify.checkPrice` | Live price and stock at Best Buy Canada | Playwright Scraper | 1 cent |
| `apify.findPlaces` | Google Maps places near a location | Google Maps Scraper | 0.4 cents a place |
| `apify.watch` | Start or stop an Apify schedule that watches a product | Playwright Scraper, on a schedule | 20 cents to start |
| `apify.crawl` | A site as clean text | Website Content Crawler | 1 cent a page |
| `apify.indexSite` | A site, written into the search folder | Website Content Crawler | 1 cent a page |
| `apify.webSource` | The web's view of a business, and where it disagrees | Website Content Crawler and Google Maps Scraper | 3 cents |

A task can use a tool only if its spec lists it. Counted costs are estimates from the Actors' list prices, set above a real run. The default cap for `apify.run` is $0.10, so a task with a small budget is not asked twice.

</Details>

<Details summary="One call, step by step, and why a hijacked agent cannot misuse it">

1. The agent calls `apify.checkPrice` through its broker socket by name. In Droid it appears as the MCP tool `apify__checkPrice`. The task has no network and no token.
2. The tool runs in the core. It reads `APIFY_TOKEN` from the vault and counts the cost against the task's budget. Over budget, the task waits for your OK, and the request names Apify as the payee and the purpose.
3. Apify runs the Actor on its servers through Apify Proxy, with its own short-lived run token, a `maxTotalChargeUsd` cap and a 120-second timeout.
4. The core cuts the result to 20,000 characters, refuses it if it contains the token, and logs the call, the result and the cost.
5. The agent gets clean JSON: price, stock and a product link, or places with ratings and addresses.

Why a hijacked agent cannot misuse it:

- The token is never in the task: not in its files, environment or network. The live run checked it was in neither task's log.
- An Actor never gets the token either. Apify starts each run with its own short-lived token. An Actor that wants full account access fails with a 403 until a person approves it in the Console, and the API cannot approve it. We first used Cheerio Scraper, which needs full access, and dropped it for that reason.
- Spending is capped twice, and results are data.
- Apify cannot approve anything. Its webhook arrives on a route with its own secret, not a paired phone's token.

</Details>

<Limits>

- Agent-Safe Page Reader is not public. The Store page returns not found until Ben switches the Apify account's public profile on in the Console; then one API call publishes it.
- The detector does not read stylesheets or run JavaScript. A page that hides text with a class defined in a stylesheet can pass, and a rephrased attack can avoid the phrase list. The agent still runs with no secrets and no network.
- `apify.checkPrice` and `apify.watch` cover Best Buy Canada only, with prices in CAD. Best Buy Canada's Conditions of Use prohibit scraping; the tool reads its public product JSON through Apify, and we disclose it here.
- The counted cost is an estimate, and Apify's reported usage leaves out the event price of pay-per-event Actors such as Google Maps.
- Apify's run endpoint takes no idempotency key, so a call cut off by a power cut starts a new run when the task resumes. These tools only read the web, so the cost is one more small run.
- A watch keeps running, and spending, until stopped.
- The offline merge gate runs the unit tests against a stubbed Apify. Live Actor runs cost credit and run only with `DEMO_LIVE=apify`.

</Limits>
