# OS references

Collected Fri Oct 23, 2026 for the "make it an operating system, not a dashboard" pass. Each image comes from the
product's official page or Apple's Human Interface Guidelines, made small for the repo. Also on the moodboard in the
[ideation board](https://www.figma.com/board/KvHiDv5HIJuGYOZDDkp8VG).

| # | Reference | Source | What to take from it |
|---|---|---|---|
| 01 | umbrelOS home | umbrel.com/umbrelos | A home server's OS in a browser tab: wallpaper, greeting, three widgets, app grid, dock. Its grid already lists OpenClaw and Hermes Agent as apps. |
| 02 | umbrelOS widgets | umbrel.com/umbrelos | Widget anatomy: one big number, its unit, a small caption. The glass only reads because the photo behind is calm. |
| 03 | ZimaOS dashboard | zimaspace.com/zimaos | A 16:9 split: system widgets in a left column, app grid on the right, all on black. |
| 04 | Synology DSM taskbar | kb.synology.com (DSM 7 help) | Running apps sit in a taskbar next to the main menu; notifications and widgets at the right. A task can be an open window. |
| 05 | SteamOS home | store.steampowered.com/steamdeck | One focused hero card, a row of smaller cards, big type, three tabs. Built to be driven from a couch. |
| 06 | iOS StandBy Live Activity | Apple HIG, Live Activities | A Live Activity scaled up for a phone across the room: two huge values and one line of detail. The box screen as StandBy for agents. |
| 07 | Dynamic Island | Apple HIG, Live Activities | A running thing as a compact pill that expands into detail. A running task as a pill. |
| 08 | Lock Screen Live Activity | Apple HIG, Live Activities | Live status of one job on the Lock Screen, no app open. Running tasks on the phone. |
| 09 | Notification banner | Apple HIG, Notifications | Icon, title, one line, time. An approval arrives as a banner over whatever is on screen. |
| 10 | Notification with actions | Apple HIG, Notifications | Full-width action buttons on the notification itself. Approve and Deny without opening anything. |
| 11 | macOS Activity Monitor | support.apple.com, Activity Monitor guide | A process table with impact columns and a live graph under it. The action log and cost as an activity monitor. |
| 12 | Nothing Glyph Matrix | nothing.tech, Phone (3) | A 25 x 25 LED dot matrix. White light on black reads across a room and suits counts and status. |
| 13 | Nothing OS widgets | nothing.tech, Phone (3) | Monochrome widgets with one red control. Keep one accent and give it one meaning: the approval. |
| 14 | Teenage Engineering OP-1 field | teenage.engineering/products/op-1 | A small, high-contrast device screen where each color matches a physical knob. Hardware first, screen second. |
| 15 | rabbit r1 screen | rabbit.tech/rabbit-r1 | A text-only list can be the whole interface on a device. Avoid its green terminal look (one of Ben's design tells). |
