GurtOS is a set of operating systems built for AI agents, on Ubuntu 24.04. Agents get real access to files, the web
and money, and never hold your keys. Every task runs as its own Linux user, in its own copy of your files, and you
can undo any one of them. It comes as GurtOS Server, GurtOS Personal and GurtOS Business. Get the install images on
the [Download](/download/) page.
